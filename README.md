# SQL Analytics Platform

Plataforma de queries SQL para análise de dados operacionais e dashboards.

Desenvolvido em 2019 para análise de dados durante experiência em órgão público.

## Estrutura

```
SQL-Analytics-Platform/
├── queries/       # Queries organizadas por módulo
├── etl/           # Scripts de ETL
├── procedures/    # Stored procedures
└── docs/          # Documentação
```

## Tecnologias

- PostgreSQL 11+
- SQL ANSI padrão

## Uso

Execute queries conforme necessidade analítica. Consulte docs/catalogo_queries.md para detalhes.
